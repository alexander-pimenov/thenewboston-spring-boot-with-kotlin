### ЗАДАЧА ОТ ЯНДЕКСА (в стиле Яндекса от бота):

Разработать систему ограничения запросов (Rate Limiting) для API

* ТРЕБОВАНИЯ:

1. Поддержка нескольких алгоритмов:
    - Token Bucket (Token Bucket - Ведро токенов)
    - Fixed Window (Фиксированное окно)
    - Sliding Window (Скользящее окно)
2. Разные лимиты для разных пользователей и endpoint'ов
3. Thread-safe реализация
4. Метрики и мониторинг
5. Гибкая конфигурация

* ДОПОЛНИТЕЛЬНО:

- Логирование превышений лимитов
- Автоматическая очистка устаревших данных
- Возможность динамического изменения лимитов

---

### 1. Token Bucket Algorithm

- Бакет наполняется токенами с фиксированной скоростью
- Каждый запрос consumes один токен
- Если токены закончились - запрос блокируется

* Принцип работы:
  - Есть "ведро" с токенами (максимальная ёмкость = maxRequests)
  - Токены добавляются с постоянной скоростью
  - Каждый запрос забирает 1 токен
  - Если токены закончились - запрос блокируется


### 2. Fixed Window Algorithm

- Считаем запросы в фиксированных временных окнах
- Например: не более 100 запросов в минуту
- Простая реализация, но возможны всплески на границах окон

### 3. Sliding Window Algorithm
- Учитывает запросы за последние N секунд
- Более точный чем Fixed Window
- Сложнее в реализации


### Итог того, что мы построили:

- 🪣 `Token Bucket` - плавное пополнение, предсказуемое поведение
- 🪟 `Fixed Window` - простота, производительность
- 🚪 `Sliding Window` - максимальная точность, справедливость
